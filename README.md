# Humanity Bridge starter website

A responsive Next.js landing page prototype for the proposed global humanitarian platform.

## Important status
This is a website preview. Donation processing, signup, campaigns, verification, backend, and admin functions are not implemented yet. Do not accept public donations through this prototype.

## Run locally
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy
Import this project into a Git provider and deploy through Vercel. The project uses the Next.js framework.
